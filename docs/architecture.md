# 系统架构

## 整体架构

本项目采用 **Web 技术栈 + 原生窗口** 的混合架构，使用 NiceGUI 框架构建用户界面。

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户界面层 (NiceGUI)                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────────┐  │
│  │  项目列表   │  │   设置页    │  │      项目详情/导出页      │  │
│  │ project_list│  │  settings   │  │        project           │  │
│  └─────────────┘  └─────────────┘  └─────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                         业务逻辑层                               │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │                    Exporter (导出器)                       │  │
│  │  - export_project()   主导出流程                           │  │
│  │  - export_pck()       导出 PCK 资源包                      │  │
│  │  - export_subpack()   导出分包                             │  │
│  └───────────────────────────────────────────────────────────┘  │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐  │
│  │   gdscripts     │  │     utils       │  │    stroge       │  │
│  │ Godot脚本执行   │  │   工具函数      │  │   本地存储      │  │
│  └─────────────────┘  └─────────────────┘  └─────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                         外部系统                                 │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────────┐  │
│  │ Godot 引擎  │  │微信开发者工具│  │     S3 CDN 存储        │  │
│  │ (headless)  │  │    CLI      │  │     (boto3)            │  │
│  └─────────────┘  └─────────────┘  └─────────────────────────┘  │

```

## 核心数据流

### 1. 项目导入流程

```
用户选择 Godot 项目目录
        │
        ▼
parse_godot_project() 解析 project.godot
        │
        ▼
提取项目名称、描述、图标
        │
        ▼
保存到 %LOCALAPPDATA%/godot-love-wechat/projects.json
```

### 2. 项目导出流程

```
用户点击导出按钮
        │
        ▼
┌─────────────────────────────────────┐
│          检查是否首次导出            │
│  (判断 game.json 是否存在)          │
└─────────────────────────────────────┘
        │
   ┌────┴────┐
   ▼         ▼
首次导出   后续导出
   │         │
   ▼         │
解压模板     │
   │         │
修改配置     │
   │         │
   └────┬────┘
        │
        ▼
┌─────────────────────────────────────┐
│        是否配置了分包？              │
└─────────────────────────────────────┘
        │
   ┌────┴────┐
   ▼         ▼
  是         否
   │         │
   ▼         ▼
导出分包   导出主包 PCK
   │         │
   └────┬────┘
        │
        ▼
    导出完成
```

## 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| UI 框架 | NiceGUI 2.9+ | 基于 FastAPI + Vue3 的 Python Web 框架 |
| 窗口容器 | pywebview 5.3+ | 原生窗口包装器 |
| 图像处理 | Pillow 11.0+ | 项目图标读取 |
| CDN 上传 | boto3 1.37+ | AWS S3 兼容存储客户端 |
| 打包工具 | PyInstaller 6.11+ | 生成 Windows 可执行文件 |
| 备选编译 | Nuitka 2.5+ | Python 到 C 编译器 |
| Python 版本 | 3.12+ | 运行时环境 |

## 配置文件说明

| 文件 | 存储位置 | 说明 |
|------|---------|------|
| `settings.json` | `%LOCALAPPDATA%/godot-love-wechat/` | 全局设置（Godot路径、微信工具路径、CDN配置） |
| `projects.json` | `%LOCALAPPDATA%/godot-love-wechat/` | 已导入的项目列表 |
| `minigame.export.json` | Godot项目目录 | 单个项目的导出配置 |
| `export_presets.cfg` | Godot项目目录 | Godot 导出预设（会被动态修改） |

## 运行时参数

```python
# main.py
ui.run(
    port=24512,           # 本地服务端口
    title="Godot Love Wechat",
    window_size=(1024, 768),  # 窗口尺寸
    native=True,          # 使用原生窗口
    reload=False,         # 禁用热重载
)
```
