## 技术规范

### 包体限制

| 类型 | 限制 | 说明 |
|------|------|------|
| 主包（首包） | 4 MB | 首屏加载必需内容 |
| 单个分包 | 20 MB | 单个包最大体积 |
| 本地总包 | 30 MB | 主包 + 所有内部分包 |
| CDN 包 | 无限制 | 网络按需加载 |
| 持久存储 | 200 MB | 本地缓存空间 |

### 运行时支持

| 技术 | 支持状态 | 说明 |
|------|---------|------|
| WebGL 1.0 | ✅ | 基础支持 |
| WebGL 2.0 | ✅ | 完全支持 |
| WebAssembly | ✅ | 重度游戏首选 |
| WASM SIMD | ✅ | 性能优化 |
| Web Audio API | ⚠️ | 部分支持 |
| WebGPU | ❌ | 不支持 |
| SharedArrayBuffer | ⚠️ | 受限 |

## 性能限制

### iOS 高性能模式

2026 年大部分高画质 3D 小游戏运行在 iOS 高性能模式下：

| 挑战 | 说明 |
|------|------|
| 内存上限敏感 | 2GB RAM 设备可用内存严格受限 |
| 强制关闭 | 超过阈值直接终止游戏 |
| 内存统计偏差 | JS Heap ≠ 实际物理内存 |

### 内存管理策略

```
设备分级：
├── 2GB RAM 设备
│   ├── 纹理分辨率：低
│   ├── 缓存上限：50MB
│   └── 同时加载资源：最少
├── 4GB RAM 设备
│   ├── 纹理分辨率：中
│   ├── 缓存上限：100MB
│   └── 同时加载资源：适中
└── 8GB+ RAM 设备
    ├── 纹理分辨率：高
    ├── 缓存上限：200MB
    └── 同时加载资源：充裕
```

## 分包策略

### 包体分配建议

```
4MB 主包分配：
├── 引擎核心 (WASM) ~2MB
├── 首屏资源 ~1MB
├── 业务代码 ~0.5MB
└── 配置文件 ~0.5MB

30MB 总包分配：
├── 主包 4MB
├── 核心分包 10MB
├── 场景分包 10MB
└── 预留空间 6MB

CDN 包（无限制）：
├── 音频资源
├── 视频资源
├── 高清贴图
└── 扩展内容
```

### 加载策略

```
启动流程：
1. 加载主包（4MB）
   └── 显示 Loading 界面
2. 初始化引擎
   └── 显示进度条
3. 加载首屏场景
   └── 用户可交互
4. 后台加载分包
   └── 静默下载
5. 按需加载 CDN 资源
   └── 用户触发时加载
```

## 跨端适配

### 平台差异

| 平台 | 渲染差异 | 输入方式 | 内存 |
|------|---------|---------|------|
| iOS | Metal 后端 | 触控 | 严格 |
| Android | OpenGL ES | 触控 | 宽松 |
| PC | ANGLE | 鼠标/键盘 | 宽松 |

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| Z-Fighting | GPU 精度差异 | 调整多边形偏移 |
| 纹理闪烁 | 压缩格式不同 | 使用通用格式 |
| 着色器错误 | GLSL 差异 | 添加兼容代码 |
| 触控延迟 | 事件处理 | 优化输入响应 |

### 输入适配

```javascript
// 跨端输入处理
const input = {
    touch: wx.onTouchStart,
    mouse: wx.onMouseDown,  // PC 端
    keyboard: wx.onKeyDown, // PC 端
};
```

## 开放数据域

### 限制

开放数据域是微信为保护用户隐私设计的隔离环境：

| 限制 | 说明 |
|------|------|
| 独立 Canvas | 不能与主域共享内存 |
| 不能加载大资源 | 受限的包体 |
| 消息通信 | 只能通过 postMessage |
| 性能受限 | 独立运行环境 |

### 通信模式

```
主域 ←→ 开放数据域
      │
      ├── wx.postMessage() → 发送消息
      └── wx.onMessage() ← 接收消息
```

## 最佳实践

### 1. 首屏优化

- 主包控制在 4MB 以内
- 使用进度条保持用户耐心
- 静态首屏 + 后台加载

### 2. 内存管理

- 建立资源分级释放机制
- 监控设备内存等级
- 动态调整资源质量

### 3. 分包加载

- 按功能模块划分
- 预加载用户可能访问的分包
- CDN 大资源按需加载

### 4. 音频处理

- 使用 InnerAudioContext
- 预加载常用音效
- 背景音乐流式播放
